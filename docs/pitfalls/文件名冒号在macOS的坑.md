# 文件名里的冒号在 macOS 上会被显示成斜杠

**首次踩到**：任务 12

## 现象

按 `yyyy-mm-dd_hh:mm:ss+主题` 的规格创建文件后，命令行 `ls` 看着正常，但在 Finder 里文件名中的 `:` 全部显示为 `/`，看上去像多了一层目录；跨平台拷贝或同步时也容易失败。

## 原因

`:` 在经典 Mac OS 的文件名中是**路径分隔符**（与 POSIX 的 `/` 角色互换）。APFS 在 POSIX 层允许 `:` 作为普通字符，但 Finder 与部分 API 仍沿用旧约定，把它呈现为 `/`。因此同一次创建在不同工具下看到的路径不同，脚本按字符串比对路径时可能对不上。

## 规避

命名一律避开 `:`，用 `-` 替代。时间戳写 `hh-mm-ss` 而非 `hh:mm:ss`——排序行为完全一致，但没有兼容风险。

## 本仓实例

`docs/logs/changelogs/` 下的日志文件名规范最终定为 `yyyy-mm-dd_hh-mm-ss_主题.md`，正是为了规避此坑。
